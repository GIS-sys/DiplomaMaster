\section{Порядок установки и использования}

\subsection{Подготовка датасета}

Исходный датасет должен иметь структуру:

\begin{verbatim}
root/
  model1/
    model1.json
    model1index1.stl
    model1index1.stp
    model1index2.stl
    model1index2.stp
    ...
  model2/
    ...
\end{verbatim}

Затем выполняется препроцессинг:

\begin{verbatim}
python MY/new_dataset.py
python MY/dataset_from_compass.py --colorparam <операция>
python MY/remove_area0.py
cp datasets/generated/train/*.obj datasets/generated/test/
\end{verbatim}

\subsection{Обучение}

\begin{verbatim}
./scripts/generated/seg/train.sh
\end{verbatim}

\subsection{Инференс}

Запуск исполняемого модуля:

\begin{verbatim}
./main.exe --path_to_input model.stp --target_folder ./output
\end{verbatim}

Параметры:
\begin{itemize}
    \item \texttt{--task auto} - автоматический режим;
    \item \texttt{--task segmentation --operation fillet} - сегментация для указанной операции;
    \item \texttt{--task classification --operation chamfer} - классификация;
    \item \texttt{-c} - кластеризация (оставить только крупнейший связный сегмент);
    \item \texttt{--remove\_largest\_area 0.05} - удалить 5\% самых больших треугольников;
    \item \texttt{-s} - сохранить визуализацию.
\end{itemize}

\subsection{Результаты}

В папке \texttt{target\_folder} создаются файлы:
\begin{itemize}
    \item \texttt{test\_0.stl} - выделенная геометрия для операции;
    \item \texttt{meta.json} - тип операции и вероятность;
    \item \texttt{test\_0.png} - визуализация (если указан флаг \texttt{-s}).
\end{itemize}
