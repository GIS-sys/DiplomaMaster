\section{Структура данных и требования к датасету}

\subsection{Форматы входных данных}
В проекте используются следующие представления данных:
\begin{itemize}
    \item \textbf{STEP} – для точной разметки датасета и интеграции с CAD-ядром.
    \item \textbf{STL} – для обучения нейросетей.
    \item \textbf{JSON} – структурированное описание операций (тип, параметры, ссылки на геометрию).
\end{itemize}

\subsection{Формирование и очистка обучающей выборки}

\subsection{Нормализация и препроцессинг}
Для каждого STL-файла выполняются:
\begin{itemize}
    \item перенос центра модели в начало координат;
    \item масштабирование к единичному размеру;
    \item триангуляция с фиксированным числом рёбер (2250) для подачи в MeshCNN.
\end{itemize}
Параметры операций нормализуются аналогично.
