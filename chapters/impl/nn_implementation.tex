\section{Реализация нейросетевой части: MeshCNN и специализированные модели}
\label{sec:nn-impl}

\subsection{Обоснование выбора MeshCNN}
Для задач сегментации трёхмерных сеток наиболее подходящей архитектурой является MeshCNN \cite{hanocka2019meshcnn}. В отличие от PointNet или DGCNN, работающих с облаками точек, MeshCNN оперирует непосредственно на рёбрах треугольной сетки, сохраняя топологию. Это критически важно для распознавания таких инженерных признаков, как скругления (плавное изменение кривизны) и фаски (плоские наклонные грани). Кроме того, MeshCNN использует инвариантные признаки (углы между гранями, синусы двугранных углов), что делает её устойчивой к разным способам триангуляции одной и той же геометрии.

\subsection{Архитектура сети}
Каждая модель (классификатор или сегментатор) построена на базе стандартной MeshCNN с незначительными модификациями. Основные компоненты:

\begin{itemize}
    \item \textbf{Входной слой}: сетка с фиксированным числом рёбер (2250). Каждое ребро характеризуется 5 признаками: длина, угол между инцидентными гранями, два двугранных угла, отношение площадей граней.
    \item \textbf{Свёрточные блоки}: последовательность из 4 свёрточных слоёв с ядром 5 (учитываются ребро и его 4 соседа). Количество каналов: 32 → 64 → 128 → 256.
    \item \textbf{Пулинг}: после каждого свёрточного блока применяется пулинг с коллапсом рёбер, уменьшающий число рёбер примерно в 1.5–2 раза (пулы: 2400 → 1800 → 1200 → 600).
    \item \textbf{Классификационная голова}: после последнего пулинга глобальный пулинг (max) и полносвязный слой с выходом 2 (вероятность наличия операции).
    \item \textbf{Сегментационная голова}: симметричная архитектура с анпулингом, восстанавливающим исходное число рёбер, и свёрткой 1×1 для получения бинарной маски.
\end{itemize}

\subsection{Функции потерь и оптимизация}
Для классификации используется бинарная кросс-энтропия:
\[
\mathcal{L}_{\text{cls}} = -\frac{1}{N}\sum_{i=1}^{N}\left[y_i\log p_i + (1-y_i)\log(1-p_i)\right],
\]
где $y_i$ - истинная метка модели (0 - операция отсутствует, 1 - присутствует), $p_i$ - предсказанная вероятность.

Для сегментации применяется взвешенная кросс-энтропия, чтобы скомпенсировать дисбаланс классов (фоновых рёбер обычно значительно больше, чем рёбер, принадлежащих операции):
\[
\mathcal{L}_{\text{seg}} = -\frac{1}{M}\sum_{j=1}^{M}\sum_{c\in\{0,1\}} w_c \cdot y_{j,c} \log p_{j,c},
\]
где $w_0$ и $w_1$ выбираются обратно пропорционально частоте классов в обучающей выборке.

Оптимизатор - Adam с начальной скоростью обучения $10^{-3}$ и уменьшением в 2 раза при плато валидационной метрики (patience=5). Обучение длится 50 эпох с размером батча 4 (ограничение по памяти GPU). Для контроля переобучения используется early stopping по accuracy на валидационной выборке.

\subsection{Обучение независимых моделей по операциям}
Для каждой из четырёх операций (\texttt{bossExtrusion}, \texttt{cutExtrusion}, \texttt{fillet}, \texttt{chamfer}) были обучены отдельные классификатор и сегментатор. Такой подход позволяет:
\begin{itemize}
    \item использовать специфичные для операции гиперпараметры (например, для \texttt{fillet} полезно увеличить вес класса 1);
    \item дообучать или заменять модель для одной операции, не затрагивая другие;
    \item легко добавлять новые операции в будущем.
\end{itemize}
Обучение проводилось на выделенных подвыборках (см. табл.~2.1). Для операций с малым числом примеров (\texttt{chamfer}) применялась аугментация данных (небольшие вращения, масштабирование, добавление шума к вершинам).
