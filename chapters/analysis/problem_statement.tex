\section{Проблема восстановления истории построения в параметрическом моделировании}

Современные системы автоматизированного проектирования (САПР) используют параметрическое моделирование, где каждый объект создаётся последовательностью операций. Однако при обмене данными между разными системами или при работе с унаследованными моделями история построения часто теряется. Инженер получает так называемую «немую» (dumb) модель, представленную только в виде граничного представления (B-Rep) или триангулированной поверхности (STL). Это существенно затрудняет редактирование, параметризацию и повторное использование модели.

Задача восстановления истории построения по финальной геометрии (обратный инжиниринг конструктивной истории) является нетривиальной по нескольким причинам:
\begin{itemize}
    \item Одна и та же итоговая геометрия может быть получена разными последовательностями операций.
    \item Локальное изменение формы может иметь множество параметрических интерпретаций.
    \item Данные могут содержать шум, неполные метаданные и ошибки выгрузки.
    \item Требуется учитывать специфику конкретной CAD-системы (в данном случае КОМПАС-3D).
\end{itemize}

В настоящей работе основное внимание уделяется разработке методов, позволяющих автоматически распознавать типовые операции (выдавливание, вырезание, скругление, фаска) по триангулированной геометрии, а затем с помощью детерминированных алгоритмов CAD-ядра восстанавливать параметры этих операций.
