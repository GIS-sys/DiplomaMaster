\section{Экспериментальная проверка и анализ результатов}

\subsection{План экспериментов}
Для оценки качества разработанного подхода были проведены следующие эксперименты:

\begin{enumerate}
    \item \textbf{Обучение классификаторов} для каждой из четырёх операций на соответствующих подвыборках. Оценка - accuracy на тестовой выборке (10\% от датасета). Сравнение проводилось с тривиальным baseline, всегда предсказывающим доминирующий класс.
    \item \textbf{Обучение сегментаторов} для каждой операции. Оценивались доля верно классифицированных рёбер (edge accuracy) для каждого класса, доля моделей с accuracy $\ge 90\%$ и $\ge 50\%$ и метрика IoU на тестовой выборке (10\% от датасета).
    \item \textbf{Тестирование на реальных деталях} визуальная оценка качества сегментации и примеры успешного автоматического упрощения в КОМПАС-3D представлены в Приложении Г.
\end{enumerate}

\subsection{Архитектурные решения и выбор гиперпараметров}
Для каждой операции (\texttt{bossExtrusion}, \texttt{cutExtrusion}, \texttt{fillet}, \texttt{chamfer}) обучались независимые классификатор и сегментатор. Это позволяет гибко настраивать гиперпараметры под специфику операции, дообучать отдельные модели и легко расширять набор поддерживаемых операций.

В ходе предварительных экспериментов было опробовано несколько конфигураций. Ниже приведены основные комбинации гиперпараметров:

\begin{itemize}
    \item \textbf{Классификация, конфигурация A}: 
        \begin{itemize}
            \item \texttt{--ncf 32 32 64 64 128}
            \item \texttt{--pool\_res 2400 2200 2000 1800 1600}
            \item \texttt{--resblocks 1}
        \end{itemize}
    \item \textbf{Классификация, конфигурация B}: 
        \begin{itemize}
            \item \texttt{--ncf 32 64 128}
            \item \texttt{--pool\_res 2400 1800 1200}
            \item \texttt{--resblocks 1}
        \end{itemize}
    \item \textbf{Сегментация, конфигурация C}: 
        \begin{itemize}
            \item \texttt{--ncf 32 32 64 64 128 128}
            \item \texttt{--pool\_res 2400 2200 2000 1800 1600}
            \item \texttt{--resblocks 3}
        \end{itemize}
    \item \textbf{Сегментация, конфигурация D}: 
        \begin{itemize}
            \item \texttt{--ncf 32 32 64 64 128}
            \item \texttt{--pool\_res 2400 1800 1200 600}
            \item \texttt{--resblocks 3}
        \end{itemize}
    \item \textbf{Сегментация, конфигурация E}: 
        \begin{itemize}
            \item \texttt{--ncf 32 64 64 128}
            \item \texttt{--pool\_res 2400 1800 1200}
            \item \texttt{--resblocks 3}
        \end{itemize}
\end{itemize}

Все модели обучались на одних и тех же наборах данных со случайной инициализацией весов; итоговая модель для каждой операции выбиралась по наилучшей точности на тестовой выборке.
