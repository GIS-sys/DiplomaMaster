\section{Экспериментальная проверка и анализ результатов}

\subsection{Методология экспериментов}
Обучение проводилось на рабочем наборе из 21~464 моделей. Для каждой операции использовалась собственная выборка, содержащая модели, в которых данная операция присутствует. Разбиение: 90\% обучение, 10\% тест. Обучение длилось 50 эпох с оптимизатором Adam (начальная скорость 0.001). Оценка качества:
\begin{itemize}
    \item для классификации – accuracy (доля правильно предсказанных наличия операции);
    \item для сегментации – доля верно классифицированных рёбер, доля моделей, в которых 90\% рёбер предсказаны верно.
\end{itemize}
Аппаратная платформа: NVIDIA RTX 4090, 64 GB RAM.

\subsection{Анализ типовых ошибок}
Наиболее частые ошибки:
\begin{itemize}
    \item Отверстия ошибочно определяются как скругления – геометрические признаки частично пересекаются.
    \item Ложноположительные рёбра – следствие ограниченного датасета и несовершенства автоматической разметки.
    \item Для операции chamfer точность ниже из-за малого числа примеров и схожести с фасками.
\end{itemize}

\subsection{Тестирование на реальных деталях}
Модуль \texttt{main.exe} был протестирован на пяти типовых деталях (см. Приложение~Б). Во всех случаях удалось выделить геометрию, соответствующую заданной операции, с высокой степенью согласованности.
