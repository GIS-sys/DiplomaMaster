\chapternoindex{Основные понятия и сокращения}

\begin{description}
    \item[API (Application Programming Interface)] - интерфейс программирования приложений, набор готовых классов, процедур, функций, структур и констант, предоставляемых приложением (библиотекой, сервисом) для использования во внешних программных продуктах.
    \item[B-Rep (Boundary Representation)] - метод представления трёхмерных тел в САПР, при котором объект описывается совокупностью граничных поверхностей, рёбер и вершин.
    \item[\texttt{bossExtrusion}] - операция формообразования в САПР КОМПАС-3D, создающая новый объём путём выдавливания эскиза (добавление материала).
    \item[CAD (Computer-Aided Design) / САПР] - система автоматизированного проектирования, программный пакет, предназначенный для создания чертежей, трёхмерных моделей и конструкторской документации.
    \item[\texttt{chamfer}] - операция создания фаски (скошенного ребра) на трёхмерной модели.
    \item[\texttt{cutExtrusion}] - операция формообразования в КОМПАС-3D, удаляющая объём путём выдавливания эскиза (вырезание материала).
    \item[DGCNN (Dynamic Graph CNN)] - архитектура нейронной сети, предназначенная для обработки неструктурированных данных, таких как облака точек, путём динамического построения графов.
    \item[\texttt{fillet}] - операция скругления рёбер трёхмерной модели.
    \item[JSON (JavaScript Object Notation)] - текстовый формат обмена данными, основанный на синтаксисе JavaScript, используемый в проекте для структурированного описания операций построения.
    \item[MeshCNN] - нейросетевая архитектура для глубокого обучения на трёхмерных полигональных сетках (meshes), оперирующая рёбрами и их признаками.
    \item[OBJ] - формат файла для представления трёхмерной геометрии, хранящий информацию о вершинах, рёбрах и гранях.
    \item[PointNet] - архитектура нейронной сети для классификации и сегментации облаков точек, обеспечивающая инвариантность к перестановке точек.
    \item[STEP (Standard for the Exchange of Product model data)] - международный стандарт (ISO 10303) для обмена данными между различными САПР; файлы STEP содержат точное параметрическое описание геометрии и структуры изделия.
    \item[STL (Stereolithography)] - формат файла для хранения трёхмерных моделей, представляющий поверхность объекта как набор треугольников (триангуляцию).
    \item[Гибридная архитектура] - в контексте данной работы подход, сочетающий нейросетевые методы (для распознавания геометрических паттернов) и детерминированные алгоритмы CAD-ядра (для точного вычисления параметров операций).
    \item[Детерминированный алгоритм] - алгоритм, который для одних и тех же исходных данных всегда выдаёт один и тот же результат и проходит по одной и той же траектории.
    \item[История построения] - последовательность формообразующих операций, их параметры и взаимосвязи, с помощью которых была создана трёхмерная параметрическая модель.
    \item[КОМПАС-3D] - система трёхмерного моделирования, разработанная компанией АСКОН, являющаяся целевой средой для интеграции разрабатываемого модуля.
    \item[Сегментация 3D-модели] - задача разбиения поверхности трёхмерной модели на связные области (рёбра, грани, треугольники), соответствующие отдельным операциям построения или семантическим частям.
\end{description}
