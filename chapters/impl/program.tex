\section{Программная реализация модуля «НейроКОМПАС-3D»}

\subsection{Дата-инженерный контур и пайплайн обучения}
Пайплайн обучения включает следующие шаги:
\begin{enumerate}
    \item Исходный датасет (папки с моделями, содержащие STL, STEP, JSON) преобразуется в промежуточный формат (Step0.stp, Step1.stp, …, Steps.txt) с фильтрацией операций.
    \item Скрипт \texttt{dataset\_from\_compass.py} по STEP и Steps.txt строит размеченные OBJ-файлы (рёбрам присваиваются метки операций).
    \item Полученный датасет (папка \texttt{datasets/generated/}) разбивается на train/test (90/10).
    \item Запускается обучение MeshCNN; веса сохраняются в \texttt{checkpoints/generated/}.
\end{enumerate}

\subsection{Контур инференса и исполняемый модуль main.exe}
Инференс включает следующие этапы:
\begin{enumerate}
    \item Загрузка STEP-файла, триангуляция в STL с адаптивным подбором deflection (бинарный поиск, чтобы число треугольников не превышало 1500).
    \item Преобразование STL в OBJ: объединение близких вершин, удаление нулевых граней.
    \item Подготовка директории для MeshCNN (папки train, test, seg, sseg), копирование OBJ в train и test.
    \item Запуск MeshCNN: нормализация, приведение числа рёбер к 2250, инференс.
    \item Постобработка результата: из coloured OBJ извлекаются рёбра с меткой 1, формируется STL-файл с выделенной геометрией (test\_0.stl), создаётся meta.json с вероятностью (для классификации).
\end{enumerate}

\subsection{Режимы работы}
Модуль поддерживает два режима:
\begin{itemize}
    \item \textbf{Автоматический} (\texttt{--task auto}): последовательно вызываются классификаторы для всех операций, выбирается операция с наибольшей вероятностью, затем запускается её сегментация.
    \item \textbf{Полуавтоматический} (\texttt{--task segmentation --operation <op>}): пользователь задаёт операцию и параметры постобработки; выполняется только сегментация.
\end{itemize}
