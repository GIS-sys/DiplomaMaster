\section{Актуальность, цель и задачи исследования}

\subsection{Актуальность}
Современное машиностроительное проектирование невозможно без систем автоматизированного проектирования (САПР). Ключевым преимуществом параметрического моделирования является наличие истории построения, позволяющей легко вносить изменения. Однако при обмене данными между различными CAD-системами или при работе с унаследованными моделями история построения часто теряется. Инженер получает лишь «немую» геометрию (STEP, STL), что существенно затрудняет редактирование и повторное использование.

В экосистеме КОМПАС-3D отсутствует встроенный инструмент для автоматического восстановления истории построения по импортированной геометрии. Разработка такого инструмента на основе методов машинного обучения позволит значительно повысить эффективность работы инженеров, сократить время на реинжиниринг и упростить параметризацию сложных моделей.

\subsection{Цель исследования}
Целью работы является разработка программного модуля «НейроКОМПАС-3D», интегрируемого со средой КОМПАС-3D, который на основе анализа геометрии модели позволяет реконструировать последовательность породивших её операций с использованием методов машинного обучения.

\subsection{Задачи исследования}
Для достижения поставленной цели в работе решаются задачи, сформулированные во введении. Основные из них включают:
\begin{itemize}
    \item анализ предметной области и существующих подходов;
    \item формирование и подготовку датасета для обучения;
    \item выбор и адаптацию нейросетевой архитектуры для сегментации 3D-моделей;
    \item разработку алгоритмов постобработки и интеграции с CAD-ядром;
    \item проведение экспериментальных исследований и оценку качества решения.
\end{itemize}
