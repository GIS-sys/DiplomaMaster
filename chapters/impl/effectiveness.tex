Был реализован код для преобразования сырого датасета в виде набора моделей и историй их построения в размеченный, очищенный датасет. В рамках этого же контура реализованы процедуры парсинга в формат, пригодный для подачи в модель. Следовательно, к настоящему моменту решена критически важная задача: данные перестали быть неформализованным набором файлов и стали объектом программно воспроизводимой обработки. Отдельно важно отметить, что выполнены работы по преобразованию датасета в цветные OBJ и по подготовке альтернативных форматов, удобных для задач сегментации и визуального контроля. Это дает основу для обучения на нескольких классах представлений.

Проект прошел стадию первичной доказательной проверки: данные стабильно читаются и обрабатываются, базовые нейронные сети обучены, дерево построения частично разбирается (в пределах обученных операций с правильным набором параметров). На основании накопленных результатов в качестве основного рабочего подхода выбран гибридный сценарий «сегментация/классификация геометрии + детерминированная CAD-реконструкция параметров».

Разработаны и обучены нейронные классификаторы и сегментаторы для выбранных типовых операций. Выбранная архитектура позволяет в дальнейшем производить дообучение каждого классификатора и сегментатора отдельно, а также добавлять новые операции без необходимости переучивания нейросетей для ранее добавленных операций.

Разработан исполняемый модуль main.exe, который позволяет осуществлять работу с геометрическими моделями в режиме инференса.

По совокупности материалов можно сделать вывод, что проект «НейроКОМПАС-3D» успешно прошел стадию первичного доказательства технологической осуществимости.

Основные результаты:

\begin{itemize}
    \item Выбрана и разработана архитектура нейронных сетей (классификаторов и сегментаторов).
    \item Сформированы требования к форматам исходных файлов и промежуточного текстового языка описания операций.
    \item Произведено обучение классификаторов и сегментаторов для операций bossExtrusion, cutExtrusion, chamfer, fillet на предоставленных заказчиком датасетах.
    \item Разработан программный модуль «НейроКОМПАС-3D» для работы в режиме инференса c возможностью интеграции с API КОМПАС-3D.
    \item Сформулированы предложения по дальнейшему улучшению и разработке
\end{itemize}
